# Hackathon Technical Reference & Rules

## 1. Track Focus & Goal

* **Selected Track:** **Push the Frontier**
* **Objective:** Solve challenges in software, robotics, manufacturing, energy, materials, or control of physical systems. Give machines new capabilities, accelerate scientific experiments, or unlock new real-world physical/hardware/scientific capabilities using Meta models.
Your project must incorporate Meta's models. Use the [Muse Spark series](https://dev.meta.ai/models/muse-spark), [Muse Wonder](https://dev.meta.ai/models/muse-wonder), [Muse Image](https://dev.meta.ai/models/muse-image) [Muse Voice Transcribe](https://dev.meta.ai/models/muse-voice-transcribe) and [SAM 3.1](https://dev.meta.ai/models/sam-3-1) through [Meta Model API](https://dev.meta.ai/products/meta-model-api), run Meta open weights models [Muse Glimmer](https://dev.meta.ai/models/muse-glimmer) and [Muse Spark Open](https://dev.meta.ai/models/muse-spark-open), and code faster with [Muse Code](https://dev.meta.ai/lp/muse-code) coding agent.

## 3. Submission & Compliance Rules

* **Repository:** Must be **Public** on GitHub.
* **Team Size:** Max 4 members (or Solo).
* **New Work & Scope:** Only features, code, and functionality built during the building window (**Oct 27 – Nov 4**) will be evaluated. Original contributions must be clearly highlighted in the codebase and submission.
* **Demo Video:** 3-minute video demonstrating working code/product functionality.
* **Banned Ideas (Disqualification Risk):**
* Medical advice / health diagnostics (e.g., skin/mental health tools).
* Basic RAG applications.
* Simple image analyzers / simple educational chatbots.
* AI job screening, nutrition coaches, personality analyzers, sports analyzers/coaches.
* Political / warfare projects.
